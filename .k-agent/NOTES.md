# Workspace notes

- RE toolchain is user-local: Ghidra in `~/tools/ghidra_12.1.4_PUBLIC`, jadx in `~/tools/jadx-1.5.6`, Android SDK in `~/Android/Sdk`, CLI tools in `~/.local/bin`. Load it with `. tools/env.sh`.
- Ghidra 12.1.4 is pinned because the GhidraMCP 2.0 extension is built for that version. Ghidra needs JDK 21, the system default stays JDK 26.
- Ghidra rejects project paths that contain a path element starting with a dot. Projects live in `analysis/ghidra-projects` inside the project folder, never under `.tmp/`.
- Headless GhidraMCP HTTP server default port is 8082. The Ghidra plugin port is 8080.
- jadx takes JVM options through the `JADX_OPTS` env var, not as a CLI flag. Use `JADX_OPTS=-Xmx6g`.
- MobSF flow: upload with `POST /api/v1/upload`, then `POST /api/v1/scan` with the returned hash, then poll `POST /api/v1/report_json` with form data `hash=`. The API key is printed in the container log as `REST API Key:`.
- MobSF container is named `mobsf`, bound to `127.0.0.1:8000`. Restart with `docker start mobsf`.
- App stack follows the onconature reference: npm only, Expo SDK 54, expo-dev-client, nativewind 2 with no preset in tailwind.config.js.
- `unstable_transformImportMeta: true` is required in babel-preset-expo, otherwise zustand 5 fails to bundle on Hermes.
- App id is `com.ktvsconnect.app`, app name `K Tvs Connect`. Original app id is `com.tvsm.connect.latam`.
- The scooter bluetooth is pure Java in the original app, package `com/tvs/bike/core/protocol` and `com/tvs/bluetooth`, not `com/tvsm`. `libBluConnect-Lib.so` is the Aptener BluArmor helmet SDK, not the scooter.
- The scooter service uuid is derived from the phone imei: `imei[0:8]-imei[8:12]-imei[12:15]9-5342-454E544F5251`. Read characteristic `00005354-...`, write `00005352-...`.
- MapLibre React Native is pinned to 10.4.2 because the project is on the legacy architecture and v11 dropped it.
- The free map stack: OpenFreeMap styles, Photon for search, Valhalla for routing with `exclude_locations` and `exclude_polygons` as top level request fields.
- The ANSV camera dataset is `https://fotodeteccion.ansv.gov.co/map/data/sast.json`, a public file with no key. Only `estado_operacion == "Operando"` is treated as active. The infraction codes it carries (C35, D02, ...) have no published legend, so the app shows them verbatim and never guesses.
- Long decompiles run inside a docker container so they survive the session: `docker run -d --entrypoint java ... jadx.cli.JadxCLI`.
- The scratch of this project stays inside the folder: `tools/env.sh` points `GHIDRA_PROJECTS` at `analysis/ghidra-projects` and the scripts use `.tmp/` instead of `/tmp`.
- The phone is connected over usb as RCUSTSEQTSK7RKSW (model 2602DPT53G). `npx expo run:android` installs the dev build on it.
- The scooter bluetooth frame tables are in `src/ble/frames.ts`, ported from `com/tvs/bike/core/protocol/apache/*`, and covered by `src/ble/parser.test.ts`.
- The frames that arrive over ble are xored with `0xEA` (the new families) or `0xEB` (the legacy ones) before the parser sees them, and the tail byte is replaced by `0xFF`. The checksum sits in the second to last slot of the decrypted frame.
- The app icons are generated by `sharp` from an svg in `.tmp/icongen/generate.js`, and `npx expo prebuild --clean` has to run again for the native resources to pick them up.
- Every screen renders through `src/components/ScreenContainer.tsx`, which owns the safe area insets. Do not pad for the system bars by hand in a screen.
- The MIUI phone can revoke INJECT_EVENTS for the adb shell, then `adb shell input tap` fails with exit 255. Unlock the phone and enable "USB debugging (Security settings)" to get the permission back.
- The docker apk build caches gradle in the named volume `k-tvs-connect-gradle`, seeded from `~/.gradle`. Mounting `~/.gradle` directly breaks the gradle daemon.
- The expo dev client shows a welcome sheet on the first launch that only a real touch dismisses, it blocks synthetic `adb input tap`.
- Metro caches aggressively in /tmp/metro-cache, so a stale bundle can hide a code change. Start it with `--clear` on a fresh port when the bundle looks wrong.
- The `write` tool reports type diagnostics against a stale snapshot in this build, so trust `npx tsc --noEmit` over the tool output.
- The cluster does its own routing: the phone only sends the destination address as text over the write characteristic, never the geometry.
- The Valhalla summary length comes back in kilometres whatever the units parameter says, so the route distance is measured from the encoded shape with `src/utils/polyline.ts`.
- The Photon geocoder needs the rider position as a bias (`lat`, `lon`) or it answers with matches anywhere in the world, for example a street in Spain for a Colombian query. It has no Spanish name data: `lang=es` is refused with a 400.
- Valhalla reports the summary length in kilometres whatever the `units` parameter says, so the distance comes from the encoded shape. Its `exclude_polygons` takes plain rings, not GeoJSON, and an exclusion removes the whole road, so the request has to be relaxed when it makes the destination unreachable.
- The cluster shows the rider name and the phone clock, not the route. The phone sends the destination address as text over the write characteristic and the cluster routes with its own engine.
- The official app sends no notification text to the cluster, only the social media counters and the media metadata.
- The app palette is TVS red and black: primary `#E4002B` in the light theme, `#FF2743` in the dark one, and the icon is a motorcycle on a red tile.
- The navigation to the bike is two packets: `5A 4E` for the control (the distance to the next turn, the time left, the distance left, the pictogram) and `5B 4F` for the instruction text.
- The location lives in one global store with a watch, and everything that moves reads it: the map, the camera distances, the remaining distance and the navigation.
- Google Maps Platform has no $200 credit any more: since 1 March 2025 it is per-SKU monthly free caps that reset on the 1st. Confirmed from the printed pricing page in maps-pricing/: Essentials 10K, Pro 5K, Enterprise 1K free calls per SKU per month. Compute Routes Essentials 10,000; Compute Routes Enterprise (motorcycle) 1,000; Navigation Request 1,000 destinations; Geocoding 10,000; Map Tiles 2D 100,000; Maps SDK Unlimited at $0. There is no hard spend cap for Maps Platform, only per-day quotas, and Google tells you to set the quota at cap/31.
- Google's terms forbid caching the route geometry and forbid turning their driving times into synthesized speech, which is exactly what the app does when it builds the cluster instruction packets. That is why the app keeps Valhalla for the routes that reach the bike.
- The Photon search only matches NAMES, not categories. Measured on 2026-11-08 from Santa Marta: "terminal de buses" returns 10 results of which 0 are local, "gasolinera" 0 local, "alameda" 0 local, while "terminal" alone returns 4 local, "pizza" 8, "banco" 10. The data is there ("Terminal de Transportes de Santa Marta" exists 3 times); the long phrase breaks the match. Photon rejects an empty q with a 400, so a category search ("all the fuel stations near me") is impossible with it.
- The Google Geocoding API needs a key: "You must use an API key to authenticate each request to Google Maps Platform APIs." A bundled key must be restricted by the Android package name and the signing cert SHA-1.
